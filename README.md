## 💻 Sobre o Projeto

Este é o meu portfólio pessoal desenvolvido para apresentar meus projetos e habilidades como **Desenvolvedor Full-Stack**. 

O objetivo principal foi criar uma interface moderna, responsiva e com identidade visual única, fugindo dos templates padrões. Além de apresentar meu trabalho, o projeto serve como demonstração prática de conceitos de **Front-end** e arquitetura de CSS.

## ✨ Funcionalidades

- **Design Responsivo:** Adaptável para Celulares, Tablets e Desktops (incluindo telas ultra-wide).
- **Formulário Funcional:** Integração com **Formspree** para envio real de e-mails.
- **Arquitetura SASS:** Uso de pré-processador para organização de estilos e variáveis.
- **UI Moderna:** Identidade visual personalizada com paleta de cores harmonizada.
- **Seção de Skills:** Exibição de competências em Front-end, Back-end (Python/Django) e DevOps.

## 🚀 Como executar o projeto

Basta clonar o repositório e abrir o arquivo `index.html` no seu navegador.

```bash
# Clone este repositório
$ git clone [https://github.com/Bruno-Braganca-Fernandes/portfolio.git](https://github.com/Bruno-Braganca-Fernandes/portfolio.git)

# Acesse a pasta do projeto no terminal
$ cd portfolio

# Instale as dependências do SASS (caso queira editar os estilos)
# Necessário ter a extensão 'Live Sass Compiler' no VS Code ou Node.js instalado
```
